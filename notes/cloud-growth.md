# Cloud Growth

Reviewed September 8, 2026. Reported segments are not interchangeable: Microsoft Cloud spans several businesses, Intelligent Cloud is a reporting segment, and Azure is a product group within it.

## Verified Microsoft Definitions

The [FY2026 Q4 release](https://www.microsoft.com/en-us/Investor/earnings/FY-2026-Q4/press-release-webcast), published July 29 for the quarter ended June 30, reports:

| Metric | Value | Scope |
| --- | ---: | --- |
| Intelligent Cloud revenue | $39.306B; +32% y/y | Reporting segment; not Azure revenue alone |
| Microsoft Cloud revenue | $59.3B; +27% y/y | Broader cloud measure spanning reporting segments |
| Azure and other cloud services growth | +43% y/y | Product-group growth; no quarterly dollar value supplied here |
| Microsoft Cloud FY2026 revenue | $214.4B | Full-year actual, not a forward estimate |
| Microsoft Cloud gross margin | 65% for Q4 | Margin of the broader cloud measure |

Source for full-year cloud revenue and margin: [Microsoft investor metrics](https://www.microsoft.com/en-us/Investor/earnings/FY-2026-Q4/metrics). Do not add the overlapping Microsoft rows together.

## Google Cloud And Demand Visibility

[Alphabet's July 22 Q2 remarks](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026/) report **Google Cloud revenue growth of 82% y/y** and **$514B of Cloud backlog**. The Cloud measure is not GCP infrastructure alone. The remarks also report approximately 22B model API tokens per minute and more than 9M monthly developers; these are usage measures, not revenue.

Microsoft's July release reports **$678B of commercial remaining performance obligations**, up 84% y/y. This is not an Azure-only measure. Backlog and RPO cover future revenue over different durations and contract scopes; neither is current recognized revenue, and the two company totals should not be compared as identical measures.
